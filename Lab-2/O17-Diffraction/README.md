# O17e - Diffraction

## Overview
This experiment investigates Fraunhofer and Fresnel diffraction
using a single slit, double slit, and diffraction grating.

The objective is to determine aperture dimensions from measured
intensity distributions and investigate the Talbot effect.

## Methods
- Optical intensity measurements using a CCD camera
- Fraunhofer and Fresnel diffraction analysis
- Numerical fitting of theoretical diffraction models
- Fast Fourier Transform (FFT) analysis
- Determination of slit widths and slit separations
- Analysis of grating parameters and Talbot length
- Measurement uncertainty evaluation
