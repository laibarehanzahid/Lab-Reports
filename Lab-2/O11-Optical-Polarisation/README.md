# O11e - Optical Polarisation

## Overview
This experiment investigates linear, circular, and elliptical
polarization using optical analyzers and quarter-wave plates.

The objective is to study polarization transformations
and identify unknown polarization states.

## Methods
- Optical measurements using a photodiode
- Jones calculus for theoretical modelling
- Investigation of quarter-wave plates
- Angular intensity measurements
- Sinusoidal curve fitting
- Characterization of unknown optical elements
- Uncertainty analysis
