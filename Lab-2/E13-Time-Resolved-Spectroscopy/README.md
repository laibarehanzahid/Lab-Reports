# E13e - Time-Resolved Spectroscopy and Impedances

## Overview
This experiment investigates transient responses in RC and
RLC circuits and their relationship to frequency-dependent
impedance and phase shift.

## Methods
- Time-resolved voltage measurements using Picoscope
- Arduino-controlled circuit switching
- Analysis of capacitor discharge curves
- Exponential decay fitting
- Damped oscillation fitting
- Fourier transformation of time-domain signals
- Impedance and phase-shift analysis
