# E14e - Semiconductor Diodes

## Overview
This experiment investigates the electrical characteristics
of silicon diodes, Zener diodes, and light-emitting diodes.

The objective is to determine characteristic diode parameters
and investigate voltage-dependent junction capacitance.

## Methods
- Current-voltage characteristic measurements
- Semiconductor diode modelling
- Shockley equation analysis
- Linear and nonlinear regression
- Zener breakdown and differential resistance analysis
- LED threshold voltage estimation
- Junction capacitance and depletion-layer analysis
