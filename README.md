## About

This repository contains selected experimental physics
laboratory reports and Python-based data analyses from
two semesters of laboratory coursework at Leipzig University.

The experiments cover mechanics, electromagnetism,
thermodynamics, optics, and semiconductor physics.

Each experiment includes a scientific report prepared
using LaTeX/Overleaf and a Jupyter notebook containing
the accompanying data analysis.
