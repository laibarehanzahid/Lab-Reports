
# E4e - Internal Resistance and Voltage Sources

## Overview
This experiment investigates the electrical characteristics of real voltage sources and solar cells.

The objective is to determine the internal resistance of a voltage source, investigate maximum power transfer, and analyse the current-voltage characteristics of a solar cell.

## Methods
- Voltage and current measurements
- Weighted linear regression
- Nonlinear curve fitting
- Determination of internal resistance
- Maximum power transfer analysis
- Solar-cell characterization
- Uncertainty propagation

## Files
- `E4e.pdf` - Laboratory report
- `E4e.ipynb` - Jupyter notebook containing the data analysis
