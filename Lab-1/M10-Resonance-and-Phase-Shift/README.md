
# M10e - Resonance and Phase Shift in Mechanical Oscillations

## Overview
This experiment investigates the behaviour of free and forced damped mechanical oscillations using Pohl's wheel.

The objective is to determine the damping constant, natural frequency, resonance frequency, and phase shift of a driven harmonic oscillator.

## Methods
- Measurement of damped and driven oscillations
- Time-series analysis using Python
- Frequency estimation using Fast Fourier Transform (FFT)
- Nonlinear fitting of damped oscillation models
- Analysis of resonance curves and phase shifts
- Uncertainty analysis
