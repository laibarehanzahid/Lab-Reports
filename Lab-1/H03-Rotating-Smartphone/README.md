
# H03e - Rotating Smartphone in an Accelerated Reference Frame

## Overview
This experiment investigates rotational motion using the built-in gyroscope and accelerometer of a smartphone.

The objective is to determine the position of the acceleration sensor inside the smartphone by analysing measured angular velocity and acceleration data.

## Methods
- Data acquisition using the Phyphox application
- Sensor data processing and visualization using Python
- Numerical differentiation and interpolation
- Least-squares fitting using SciPy
- Symbolic regression
