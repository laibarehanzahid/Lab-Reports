
# E7e - Magnetic Fields in Coils

## Overview
This experiment investigates the spatial distribution of magnetic fields generated by different coil configurations.

Measurements were performed using a magnetometer connected to an Arduino microcontroller.

The results are compared with theoretical predictions from magnetostatics.

## Methods
- Magnetic-field measurements using a magnetometer
- Investigation of solenoids and circular coils
- Analysis of Helmholtz coil configurations
- Background magnetic-field correction
- Comparison of experimental data with theoretical models
- Monte Carlo uncertainty propagation
